💱 Currency Converter App (Flutter)

A modern and responsive Flutter application that converts currencies in real-time using live exchange rates. The app includes a sleek UI, dark mode support, local history storage, and smooth animations for a better user experience.

📌 Features
🌍 Real-time currency conversion using live API
🔄 Swap currencies with one tap
🌙 Dark / Light mode toggle
💾 Save conversion history locally
🧾 View past conversions in history screen
📱 Splash screen for professional startup experience
✨ Smooth button animations
🎨 Clean and modern UI design
🛠️ Tech Stack
Flutter (Dart)
HTTP package (API integration)
SharedPreferences (local storage)
Material Design
📦 Installation
1. Clone the repository
git clone https://github.com/your-username/currency-converter-app.git
2. Move to project folder
cd currency-converter-app
3. Install dependencies
flutter pub get
4. Run the app
flutter run
🔌 API Used

This project uses a free exchange rate API:

https://api.exchangerate.host

It provides real-time currency conversion data.

🧠 How It Works
User enters an amount
Selects "From" and "To" currencies
App fetches live exchange rate from API
Converts and displays result instantly
Saves result into local history
